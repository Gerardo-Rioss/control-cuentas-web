# Full Redesign — Control Cuentas Web

> **Para implementar con OpenCode + SDD:** `cd ~/repos/gerariosdev/control-cuentas-web && opencode` y seguí las fases con `/sdd-new -> "nombre-fase"`.

**Goal:** Transformar el dashboard funcional actual en una experiencia tipo app bancaria profesional con sidebar, charts, dark mode, animaciones y responsive total.

**Tech Stack:** Next.js 16.2.9 · shadcn/ui · Tailwind v4 · Recharts · next-themes · framer-motion · lucide-react

**Arquitectura:** Feature-based folders dentro de `src/components/`. Cada feature tiene su propia carpeta con componentes, hooks y tipos. El layout existente se reemplaza por un AppShell con sidebar.

## 📦 Fase 0: Setup de dependencias

**Objetivo:** Instalar las librerías necesarias y configurar el tema.

**Archivos a modificar:**
- `package.json` — agregar dependencias
- `src/app/layout.tsx` — agregar ThemeProvider
- `tailwind.config.ts` o `src/app/globals.css` — configurar dark mode con clase

**Dependencias a instalar:**
```bash
npm install recharts next-themes framer-motion
```

**Config ThemeProvider** en `src/app/layout.tsx`:
```tsx
import { ThemeProvider } from "next-themes"

export default function RootLayout({ children }) {
  return (
    <html lang="es" suppressHydrationWarning>
      <body>
        <ThemeProvider attribute="class" defaultTheme="system" enableSystem>
          {children}
        </ThemeProvider>
      </body>
    </html>
  )
}
```

**Verificación:** `npm run build` compila sin errores.
