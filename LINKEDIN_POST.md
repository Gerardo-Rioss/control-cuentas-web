🚀 **Acabo de publicar mi proyecto full-stack más completo: Control Cuentas** 💰

Una app de finanzas personales para registrar ingresos/gastos, visualizar reportes con gráficos interactivos, y administrar categorías — todo con autenticación segura y modo oscuro.

**🧱 Stack:**
Next.js 16 · TypeScript · Prisma 7 · PostgreSQL · Tailwind v4 · shadcn/ui · Recharts · NextAuth v5 · Vitest

**✨ Features destacadas:**
📊 Dashboard con 3 tipos de gráficos (torta por categoría, evolución mensual, comparativo)
💸 CRUD completo de movimientos con toggle pagado/pendiente
🏷️ CRUD de categorías con 12 colores personalizables
🔐 Autenticación JWT + bcrypt
🌙 Dark mode + responsive (desktop/mobile)
🧪 5 suites de tests en las APIs

**🔗 Live Demo:** https://control-cuentas-6okkse5b4-gerariosdev-projects.vercel.app
**📦 Código:** https://github.com/gerariosdev/control-cuentas-web

PD: Además de la app en sí, armé todo el pipeline de CI/CD con Vercel + Neon (PostgreSQL serverless) y automatización con AI-assisted development usando OpenCode + SDD + code review automático.
